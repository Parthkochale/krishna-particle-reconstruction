# ✦ Krishna Particle Reconstruction ✦

A Python + OpenCV + NumPy project that celebrates Krishna Janmashtami with creative coding.  
This particle system reconstructs Lord Krishna from neon chaos into photorealistic art.

## ✨ Features
- 20,000 particles swirling, colliding, and forming Krishna’s silhouette
- Multiple phases: Chaos → Storm → Attraction → Formation → Definition
- Neon palette with glow bloom effects
- Restart anytime with `SPACE`, exit with `ESC/Q`

## ⚙️ Requirements
- Python 3.8+
- OpenCV (`pip install opencv-python`)
- NumPy (`pip install numpy`)

## 🚀 Run
Clone the repo and run:
```bash
python krishna_particles.py
